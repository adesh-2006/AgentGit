# AgentGit VS Code Extension

Visual behavioral diffs, prompt linting, and regression tracking for AI agents right inside VS Code.

## Features

- **Prompt Linter (`AgentGit: Lint Current Prompt File`):** Scan active prompt files for contradictory constraints, unbounded length, and prompt injection risks.
- **Behavioral Diff Viewer (`AgentGit: Show Behavioral Diff`):** Compare any two snapshots directly in the terminal or browser.
- **Web Dashboard (`AgentGit: Open Web Dashboard`):** Launch the interactive local AgentGit web UI with one click from the status bar.
- **Snapshot Browser (`AgentGit: List Snapshots`):** View all historical agent versions.

## Requirements

Ensure `agentgit` is installed in your Python environment:
```bash
pip install agentgit
```
